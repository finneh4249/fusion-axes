Usage Notes & Integration

Tokens are declared as CSS variables for immediate use in NationBuilder theme CSS or to port straight into a React app later. Use --color-action-primary-hover for accessible small-button states. Reserve gradients for hero/CTA components only. Pair --core-mint and --core-lavender with dark text (#010102).

Example token usage (CSS):
.site-header { background: var(--color-bg-page); color: var(--color-text-primary); }
.cta { background: var(--color-action-primary); color: #fff; }
.card { background: var(--color-bg-surface); border-radius: 12px; }
Accessibility reminder:
Core Magenta (#C926F2) only meets WCAG contrast for large/bold white text. Use --color-action-primary-hover (#A01DC3) or text color #010102 for small text/buttons.
Reduced-motion:
All animations respect prefers-reduced-motion. Keep motion short and purposeful (180–250ms).
